⚙︎ 投稿ボタンの準備

「投稿する！」と「直してほしい」を使うには、GitHubの鍵（トークン）を1回だけ入れます。鍵はこのスマホの中だけに保存され、ほかには送られません。

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access：Only select repositories → nekonowakusei-web
  3. Permissions：Contents と Pull requests を Read and write
  4. できた鍵（github_pat_…）を下に貼る
