# ねこの惑星マガジン 編集方針

北九州・小倉の保護猫施設「ねこの惑星」が出す猫のマガジン。週3本（月・水・金）。
AIが下書きを作り、**藤島さんがPRを読んでマージしたものだけが公開される**。

---

## 1. 誰に向けて書くか

- 猫を飼っている人、これから保護猫を迎えたい人
- 北九州・福岡で猫と暮らす人
- 「就労支援×保護猫」に興味がある人、利用を考えている人

読み終わったあと「へえ、誰かに話したい」か「今日から試せる」のどちらかが残る記事にする。

## 2. 記事の型（ローテーション）

| 型 | 中身 | カテゴリの目安 |
|---|---|---|
| ニュース解説 | 最近の研究・制度・統計を噛み砕く。「で、うちの猫だとどうなの？」まで書く | 猫の雑学／暮らし |
| 実用ガイド | 季節の困りごと（寒さ、換毛期、梅雨、花火、帰省）の具体的な対処 | 暮らし／迎える準備 |
| 雑学 | 体のしくみ、行動の理由、歴史。一次資料つき | 猫の雑学 |
| 北九州 | 市の動物愛護センター、地域の制度、イベント、統計 | 北九州 |
| 施設から | テン・ムギの観察、お世話の工夫、就労支援の現場 | 就労支援／暮らし |

同じ型・同じカテゴリが3本続かないようにする。`magazine/log.md` で確認する。

## 3. 文体ルール（AI臭さを消す）

**やること**
- です・ます調。ただし文末を散らす（「〜です」「〜ます」だけで4文続けない。体言止め、「〜でした」「〜だそう」「〜とのこと」を混ぜる）
- 一般論のあとに必ず**具体**を置く。数字、固有名詞、テンかムギの実例
- 1記事に1回は、テンかムギの「その場面」を書く（例：ムギは換毛期になるとブラシを見ただけで逃げて、テンは自分から寝転がる）。`magazine/cats.md` にある事実と、藤島さんのメモだけを使う。**作り話の猫エピソードは書かない**
- 見出しは疑問形か具体的な言い切り。「〜について」「〜のポイント」は使わない
- 冒頭3行で「何がわかるか」を書く。前置きの挨拶はしない
- 締めは、要約ではなく「次にやること」か「テン・ムギの一言」で終える

**やらないこと**（`npm run lint:articles` で機械チェック）
- 「いかがでしたか」「この記事では」「見ていきましょう」「ことが大切です」「さまざまな」などの定型句
- 「！」の連発（1記事3回まで）
- 箇条書きだらけの記事。箇条書きは1記事2か所まで、残りは文章で
- 「〜と言えるでしょう」「〜ではないでしょうか」のぼかし
- 中身のない形容（素敵な、癒し、愛くるしい）。様子をそのまま書く

## 4. 事実と出典

- 出典は**2件以上**。優先順位：論文・大学・学会 ＞ 環境省・自治体・獣医師会 ＞ 大手報道 ＞ 専門メディア。まとめサイト・個人ブログ・SNSは出典にしない
- 数字には必ず出典を付ける。出典に書いていない数字は書かない
- 病気・薬・食べ物の安全性は断定しない。最後は「気になる症状があれば動物病院へ」につなぐ（毎回の定型文にはしない）
- 書き終えたら、**書いた本人ではない別のエージェント**が、本文の主張を1つずつ出典と照らし合わせる（ファクトチェック）。確認できなかった文は消すか直す
- 出典の文章をそのまま写さない。引用は1出典1か所、15字未満まで

## 5. 写真

- 使うのは**テン・ムギの写真だけ**（非公開リポジトリ `nekonowakusei-photos`）。外部サイトの写真は使わない（著作権のため）
- **人が少しでも写っている写真は使わない**（手・足・服もNG）。`magazine/photo-catalog.md` の「人」が×のものから選び、取り込む前に実物を目で確認する
- 1記事に表紙1枚＋本文1〜3枚。記事の内容と合う写真にする（寝る話なら寝ている写真）
- 取り込みは `node scripts/photos.mjs add <写真フォルダ> <番号> <記事スラッグ>-<番号>`（長辺1600px、位置情報を削除）
- `alt` は「何をしているどちらの猫か」を具体的に書く
- 写真の下に一言キャプションを付けるときは、画像の次の行に `*キャプション*` だけを書く
- 使った写真は `magazine/photo-catalog.md` の内容欄の最後に「使用:スラッグ」と追記する（使い回しを避ける）

## 6. ファイルの書き方

`src/content/articles/<英数字スラッグ>.md`

```md
---
title: 32文字前後。検索される言葉を前に
description: 80〜120文字。何がわかるかを具体的に
category: 迎える準備 | 暮らし | 猫の雑学 | 北九州 | 就労支援
published: 2026-11-16
cover: ../../assets/cats/mag/スラッグ-0123.jpg
coverAlt: 窓辺で日なたぼっこをするムギ
cats: [ムギ]
sources:
  - name: 出典の名前（発行元「タイトル」）
    url: https://...
---

本文（1500〜3000字、## 見出し3つ以上）

![ソファで丸くなって眠るテン](../../assets/cats/mag/スラッグ-0456.jpg)
*寒い日のテンは、だいたいこの形。*
```

## 7. 公開前チェック（全部通ってからPR）

```sh
npm run lint:articles   # AI臭さ・出典・写真・分量
npm run build
npm run check:seo
```

PRの本文には次を書く：記事の要約3行／出典一覧／ファクトチェックの結果（直した箇所）／使った写真の番号／**藤島さんに確認したいこと**（あれば）。
